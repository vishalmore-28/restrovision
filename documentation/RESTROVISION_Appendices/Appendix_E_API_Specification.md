# APPENDIX E: RESTROVISION REST & WebSocket API Specification

## 1. Authentication Endpoints
- `POST /api/v1/auth/login`: Authenticate staff credentials, return JWT access token and HTTP-only refresh cookie.
- `GET /api/v1/auth/me`: Validate active JWT session, return user profile and assigned roles.
- `POST /api/v1/auth/refresh`: Issue new access token using valid refresh token.
- `POST /api/v1/auth/logout`: Revoke active session token and invalidate refresh token.

## 2. Table Management Endpoints
- `GET /api/v1/tables`: Retrieve all dining tables with real-time occupancy status and session timers.
- `POST /api/v1/tables/{tableId}/seat`: Seat party at table, assign waiter, and initiate dining session.
- `POST /api/v1/tables/{tableId}/clean`: Mark table sanitization complete, returning status to AVAILABLE.
- `PUT /api/v1/tables/{tableId}/status`: Manager manual status override (with 120s AI lockout protection).

## 3. Edge AI Ingestion Endpoints
- `POST /api/v1/ai/events`: Ingest cryptographically signed camera telemetry (`TABLE_OCCUPIED`, `TABLE_VACATED`, `CALL_WAITER`).
  - Headers: `X-Signature` (HMAC-SHA256), `X-Timestamp` (Anti-replay window ±300s).
- `GET /api/v1/cameras`: List all configured CCTV streams and status.
- `POST /api/v1/cameras/zones`: Define geometric polygon coordinates for dining table zones.

## 4. Kitchen & Order Endpoints
- `GET /api/v1/orders`: Retrieve active kitchen tickets filtered by milestone (`PENDING`, `COOKING`, `READY`).
- `POST /api/v1/orders`: Submit new customer dining order.
- `PATCH /api/v1/orders/{orderId}/status`: Update order milestone from Kitchen Display System (KDS).

## 5. WebSocket STOMP Channels
- `/ws`: STOMP WebSocket connection endpoint with JWT handshake authentication.
- `/topic/tables`: Broadcasts real-time table occupancy transitions and waiting alert levels.
- `/topic/orders`: Pushes incoming orders directly to kitchen KDS screens.
- `/topic/alerts`: Dispatches urgent waiter call chimes and escalation events.
- `/topic/tasks`: Broadcasts housekeeping turnover tasks generated by Sanitization Gate §6.1.
